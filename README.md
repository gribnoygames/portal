# Портал «Мой Не Сам»

- **Вариант:** Портал заявок - Мой Не Сам
- **Автор:** Смелый Владимир, Скорых Дмитрий, группа РВП-2.24
- **Стек:** XAMPP (Apache + MariaDB + PHP 8.2), VS Code

## Как запустить

1. Открыть `C:\xampp\xampp-control.exe`, запустить **Apache** и **MySQL**.
2. Открыть в браузере `http://localhost/portal/`.
3. Главная страница — `index.php`, выводит дату и версию PHP.

## Проблемы при запуске

- _Пример:_ Apache не стартовал — порт 80 занимал Skype. Закрыл Skype, Apache запустился.
