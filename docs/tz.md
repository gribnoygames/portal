# ТЗ-лист: Портал заявок «Мой Не Сам»

## 1. Общие сведения
**Заказчик:** Сервис бытовых услуг «Мой Не Сам».
**Цель:** Приём заявок на бытовые услуги онлайн и их обработка мастером-администратором.
**Стек:** XAMPP (Apache + MariaDB + PHP 8.2), HTML5, CSS3, JavaScript.

## 2. Роли
| Роль | Доступ |
|---|---|
| Гость | Регистрация, вход |
| Клиент | Создание заявки, просмотр своих заявок, выход |
| Мастер-администратор (`adminka`/`password`) | Все заявки, смена статуса, причина отклонения, стоимость услуги, выход |

## 3. Функциональные требования (ФТ)
*   **ФТ-01** Регистрация с полями: логин, пароль, ФИО, телефон, email.
*   **ФТ-02** Логин уникален. При совпадении выводится сообщение «Логин занят».
*   **ФТ-03** Вход по логину и паролю. При ошибке выводится «Неверный логин или пароль».
*   **ФТ-04** После входа клиент попадает на страницу «Мои заявки», администратор — в админ-панель.
*   **ФТ-05** Клиент может создать заявку с указанием вида услуги, описания задачи, адреса/самовывоза и желаемой даты.
*   **ФТ-06** При выборе услуги «Другое» появляется обязательное поле для описания.
*   **ФТ-07** Клиент видит только свои заявки и их текущие статусы.
*   **ФТ-08** Администратор видит все заявки в системе.
*   **ФТ-09** Администратор может менять статус заявки (Диагностика, В ремонте, Готово к выдаче, Отклонено).
*   **ФТ-10** При статусе «Отклонено» причина обязательна для заполнения.
*   **ФТ-11** Администратор может указать стоимость услуги.
*   **ФТ-12** Выход из системы (`logout`) доступен клиенту и администратору.

## 4. Требования к данным и валидации
| Поле | Правило | Пример верного значения |
|---|---|---|
| Логин | Только латиница, ≥ 6 символов, уникальный | `master1` |
| Пароль | ≥ 6 символов | `qwerty` |
| ФИО | Кириллица и пробелы | `Иванов Иван Иванович` |
| Телефон | Строгий формат `+7(XXX)-XXX-XX-XX` | `+7(912)-345-67-89` |
| Email | Формат email | `ivan@mail.ru` |
| Желаемая дата | Формат даты (не в прошлом) | `25.10.2026` |

## 5. Нефункциональные требования (НФТ)
*   **НФТ-01** Адаптивность: все страницы корректно отображаются при ширине 390px.
*   **НФТ-02** Пароли в базе данных хранятся только в виде хеша (`password_hash`).
*   **НФТ-03** Страницы клиента и админа недоступны без авторизации (редирект на `login.php`).
*   **НФТ-04** Кодировка UTF-8 во всех файлах и в БД (`utf8mb4`).
*   **НФТ-05** Разделение прав доступа: клиент не может открыть `admin.php` по прямой ссылке.

## 6. Справочники
*   **Статусы:** Диагностика, В ремонте, Готово к выдаче, Отклонено.
*   **Виды услуг:** Уборка квартир, Мелкий бытовой ремонт, Сборка мебели, Помощь при переезде.
