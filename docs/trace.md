# Матрица трассировки требований

| Требование | Страница (Файл) | Таблица.Поле в БД | Как проверить |
|---|---|---|---|
| **ФТ-02** Уникальный логин | `register.php` | `users.login` (UNIQUE) | Попробовать зарегистрировать двух юзеров с одним логином. |
| **ФТ-03** Ошибка входа | `login.php` | `users.login`, `users.password` | Ввести неверный пароль, проверить текст ошибки. |
| **ФТ-04** Редирект по роли | `login.php` | `users.role_id` | Войти как клиент (в `orders.php`) и как админ (в `admin.php`). |
| **ФТ-06** Поле «Другое» | `order_new.php` | `orders.description` | Выбрать вид услуги «Другое», проверить появление поля. |
| **ФТ-07** Только свои заявки | `orders.php` | `orders.user_id` | Войти под разными клиентами, проверить, что списки разные. |
| **ФТ-10** Причина отклонения | `admin.php` | `orders.cancel_reason` | Попробовать поставить статус «Отклонено» без причины. |
| **ФТ-11** Стоимость услуги | `admin.php` | `orders.total_cost` | Ввести цену, проверить отображение у клиента. |
| **НФТ-02** Хеш пароля | `register.php` | `users.password` | Посмотреть в phpMyAdmin, пароль должен быть вида `$2y$10$...` |
| **НФТ-05** Защита админки | `admin.php` | `users.role_id` | Попробовать открыть `admin.php` под клиентом (должен быть редирект). |
