## 4. Неявные требования (с цветовой пометкой источника)

1. <span style="color:#FFC0CB; font-weight:bold">Клиент не должен видеть чужие заявки.</span> Следует из фразы «Клиент видит **свои** заявки». <span style="color:#FFFF00">Значит, заявка хранит `user_id`, а в `orders.php` выборка фильтруется по текущему пользователю.</span>
2. <span style="color:#00FF00; font-weight:bold">`admin.php` недоступна обычному клиенту по прямой ссылке.</span> Следует из наличия отдельной роли «мастер-администратор»: раз есть разграничение прав, страница админа должна проверять роль на сервере, иначе клиент откроет её вручную.
3. <span style="color:#FFC0CB; font-weight:bold">При выборе «самовывоз» поле адреса не должно быть обязательным (и наоборот).</span> Следует из фразы «адрес **или** самовывоз»: это альтернатива, а не два обязательных поля.
4. <span style="color:#FFC0CB; font-weight:bold">При выборе вида техники «другое» появляется поле описания.</span> Следует из формулировки «другое — с описанием».
5. <span style="color:#FFC0CB; font-weight:bold">Причина отклонения должна сохраняться в БД.</span> Следует из того, что <span style="color:#00FF00">клиент</span> «видит свои заявки и их статусы»: причина отклонения — часть статуса, и клиент должен её видеть.
6. <span style="color:#FFC0CB; font-weight:bold">Стоимость ремонта видит клиент в своих заявках.</span> Следует из логики: <span style="color:#00FF00">мастер</span> «указывает стоимость», а <span style="color:#00FF00">клиент</span> видит заявку и её состояние.

## 6. Контрольные вопросы (краткие ответы)

1. <span style="color:#00FF00">Гость</span> не авторизован и видит только вход/регистрацию; <span style="color:#00FF00">клиент</span> вошёл и имеет доступ к <span style="color:#FFFF00">созданию и просмотру своих заявок</span>. Гостя надо учитывать, чтобы не показывать защищённые страницы и корректно редиректить на вход.
2. **Неявное требование** — не записанное прямо, но следующее из логики. Пример из «Мой Не Сам»: <span style="color:#FFC0CB">клиент не должен видеть чужие заявки</span> (из фразы «история **своих** заявок»), и <span style="color:#00FF00">`admin.php` не должна открываться обычному пользователю</span>.
3. <span style="color:#FFC0CB">Список услуг и статусов — дословно</span>, потому что эксперт сверяет их с текстом ТЗ; «услуга из головы» или другой набор статусов = потеря баллов.
4. **Пять экранов типичного портала:** <span style="color:#FFFF00">регистрация, вход, список заявок клиента, новая заявка, админ-панель</span> (плюс действие logout).
5. <span style="color:#FFFF00">Чек-лист в последние 20 минут</span> — дешёвые баллы: проходим по пунктам «[ ]», ставим галочки и добираем пропущенное, пока есть время.
